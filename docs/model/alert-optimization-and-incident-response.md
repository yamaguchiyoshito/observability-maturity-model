# A4. アラート最適化と障害対応

**能力の定義**: システムの異常を適切に検知し、ノイズを抑えながら迅速な対応を実現する能力。

## レベル一覧

| レベル | 名称 | 説明 |
|---|---|---|
| [レベル1](#level-1) | 属人的 | 固定しきい値のアラートのみで運用されており、誤検知・見逃しが多く、障害対応も手動かつ反応的に実施されている。 |
| [レベル2](#level-2) | プロセス確立 | アラートの重要度や対象を整理し、しきい値調整などによるノイズ削減に取り組んでいるが、改善効果は限定的である。 |
| [レベル3](#level-3) | 組織標準化 | 動的しきい値や異常検知の仕組みを導入し、アラートの精度を向上させ、不要な通知を削減している。 |
| [レベル4](#level-4) | 定量管理 | アラート履歴や影響度をもとに、AIによる優先度付けや自動チューニングを行い、判断支援と迅速な対応を実現している。 |
| [レベル5](#level-5) | 継続的最適化 | 異常検知から原因推定、対処アクションの実行までを自動化し、オペレーターの介入なしでアラート処理を完結させている。 |
